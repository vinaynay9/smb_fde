# Contractor sites (Austin)

Website mockups for 9 Austin-area contractors with no working website, plus the cold-email drafts.

- `sites/<business>/` – raw HTML (index, quote, book). Internal only. Photos are hotlinked from the business's own Google Maps listing.
- `previews/` – watermarked full-page images. These are the only thing prospects should ever receive.
- `outreach-emails.md` – one email per business; subject-line × price test ($2,000 / $2,250 / $2,500).
- `shortlist.md`, `emails.md` – research notes and confirmed contact emails.

Keep this repo private: prospects should never get the HTML.
